# Terraform STACKIT Volume module

Terraform module which creates and manages [STACKIT block volumes](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/volume) (data disks) on [STACKIT](https://www.stackit.de/en/), and optionally attaches them to existing servers.

This module is the dedicated home for volume **creation** — the `terraform-stackit-compute` module stays focused on the server and only *attaches* pre-existing volume IDs.

This repository is not from the official STACKIT organization.

## Usage

```hcl
module "volume" {
  source  = "terraform-stackit-modules/volume/stackit"
  version = ">= 1.0.0"

  project_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"

  volumes = {
    # A bare, sized data volume.
    data = {
      availability_zone = "eu01-1"
      name              = "app-data"
      size              = 50
      performance_class = "storage_premium_perf6"
    }

    # A volume created from an image source (an image source still needs `size`).
    from_image = {
      availability_zone = "eu01-1"
      name              = "app-from-image"
      size              = 20
      source = {
        type = "image"
        id   = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
      }
    }

    # A volume that is also attached to an existing server.
    attached = {
      availability_zone   = "eu01-1"
      name                = "app-extra"
      size                = 20
      attach_to_server_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
    }
  }

  labels = {
    managed_by = "terraform"
  }
}
```

See [`examples/basic`](./examples/basic) for a self-contained example (requires only `project_id`).

## Encrypted volumes

Volumes can be encrypted with a key-encryption-key from STACKIT-KMS:

```hcl
volumes = {
  secure = {
    availability_zone = "eu01-1"
    size              = 20
    encryption_parameters = {
      kek_key_id      = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
      kek_key_version = 1
      kek_keyring_id  = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
      service_account = "sa@sa.stackit.cloud"
    }
  }
}
```

## Notes

- A volume needs a `size` in every case EXCEPT when created from a `volume`, `snapshot` or
  `backup` source (those carry their own size). A `size` is still required for a bare volume AND
  for an `image` source — the STACKIT API rejects an image source without `size`. `size` can
  only be updated to a **larger** value.
- The `volumes` map is keyed by a **stable identifier**, which is reused as the attachment key.
  This keeps `for_each` off the created `volume_id` (known-after-apply) when attaching.
- `attach_to_server_id` is optional per volume — omit it to create a volume without attaching it.
- `encryption_parameters` are only present in state after creation; they are not returned by
  imports or the data source.

## Terratest

The `test/` directory holds a Terratest integration test that applies the `examples/basic` root module against a real STACKIT project (requires `STACKIT_SERVICE_ACCOUNT_KEY` and `STACKIT_PROJECT_ID`).

```bash
cd test
go mod init github.com/terraform-stackit-modules/terraform-stackit-volume
go get github.com/gruntwork-io/terratest@v1.0.1
go mod tidy
go test -v -timeout 45m ./...
```
